v1.0.2 (2026-11-04)  Site Codes: Lease name -> 2-letter site code
  Added   : Site Codes tab and Config\SiteCodes.json. The device registry's
            Lease column holds the site name (Belridge, South Midway ...); the
            table maps it to the code used in driver names (BL, SM ...), so
            names stay within 15 characters. Shipped with Bakersfield BK,
            Belridge BL, Coalinga CG, North Midway NM, San Ardo SA,
            South Midway SM, Ventura VN. Matching ignores case and extra
            spaces; a Lease that is (or starts with) a code still works.
            Saved to Settings\SiteCodes.json; editable with the admin password.
  Changed : Activity log: rows skipped for "no site code" list the Lease names
            to add on the Site Codes tab.

v1.0.1 (2026-11-04)  Lease values with more than the site code
  Fixed   : Build preview skipped every device when the Lease column held more
            than the bare code ("BL - Belridge", "BL-01" ...): the site code is
            now the first two letters when they are followed by a space, dash,
            bracket, digit or similar. A Lease column exported under a longer
            name ("Lease Name", "Lease Code" ...) is found too.
  Added   : Activity log lists the Lease values that gave no site code (with
            counts) and any needed column the pasted data does not have.

v1.0.0 (2026-11-04)  Created from AppTemplate v1.0.20 - rewrite of RSLinx Utility.ps1
  Added   : Drivers tab. Paste device-registry CSV rows (or load the file);
            Allen-Bradley devices only; Primary and Secondary IPs; drivers
            grouped by site (Lease) and VLAN and named SITE(VLAN)DESCRIPTION
            from the VLAN lookup table (default SITE(3rd octet)SCADA when a
            subnet is not in it). Editable preview with a site picker, then
            Add to this PC (adds missing IPs, into the same-named driver when
            there is one) or Overwrite this PC. Drivers on this PC: remove
            selected IPs, copy to preview. Backups (Name,Node CSV, compatible
            with the old tool and RSLinx.csv): save / restore to preview /
            delete; an automatic backup before every registry change.
  Added   : VLAN Lookup tab: the table from RSLinx.xlsx (VlanLookup sheet),
            editable, validated (IP base, CIDR, duplicates, 15-character name
            limit), Import / Export CSV, saved to Settings\VlanLookup.json.
  Added   : RSLinx tab: embedded RSLinx Classic control panel (RSLINXCP.EXE)
            and PC facts (IP, admin rights, RSLinx service, Rockwell software).
  Added   : Environment fields: Driver backup folder (UNC), Manufacturer to
            include.
  Changed : Registry written directly (32-bit view of HKLM\SOFTWARE\Rockwell
            Software\RSLinx\Drivers\AB_ETH) instead of importing .reg files.
  Removed : Template sample tabs (Tab 1-4); RSLinx.bat (run the EXE; the
            Drivers tab offers Restart as administrator); unused leftovers of
            the old script (RSLinxAll.reg path, RSLINX.EXE paths,
            Test-Administrator never called).
